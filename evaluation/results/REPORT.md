## 3. 指标定义

| 指标 | 定义 |
| --- | --- |
| Recall@K | 前 K 个结果覆盖的相关记忆数 / 全部相关记忆数（等级 > 0） |
| Precision@K | 前 K 个结果中相关记忆数 / K |
| Hit@K | 前 K 个结果是否至少命中一个相关记忆 |
| MRR@K | 第一个相关结果排名倒数；未命中为 0 |
| MAP@K | 各命中位置 precision 的均值，再对相关结果数归一化 |
| nDCG@K | 增益 2^rel-1，折损 1/log2(rank+1)，用理想排序归一化 |
| 候选召回 | 标注相关项中被候选集覆盖的比例（先看召回瓶颈，再看排序） |

相关性等级：2 = 直接答案，1 = 相关背景，0/未标注 = 无关。Recall/Precision/MRR/MAP/Hit 将等级 1、2 都视为相关；nDCG 使用等级增益。

## 8. 短板与建议

1. **自动意图分类（高）**：memory_type=all 时准确率 24.0%，规则在无关键词命中时一律退化为 mixed，导致 Wiki/事件单通道查询也走双路。建议扩充领域词表或改用轻量分类器，并保留 mixed 作为兜底。
2. **Wiki 候选召回（高）**：代理阈值下 73.9%，生产阈值 0.15 下仅 34.8%。知识块文本短、口语查询与词条表述差异大，建议为 Wiki 增加标题/别名/关键词索引，或对 Wiki 使用更低的候选阈值并依赖精排兜底。
3. **长序列排序（中）**：长序列切片 nDCG@10 = 58.0%，明显低于整体。时间衰减与熟悉度可能把早期关键决策压下去，建议对“第 N 次/最早一次”类查询引入显式序列位置特征。
4. **反馈信号（中）**：nDCG 仅 +0.004，1 升 1 降。建议评估提高 familiarity_beta 或在排序阶段加入反馈特征，但必须用在线指标验证。
5. **实体别名（中）**：精确匹配把 `Alpha 项目` 与 `项目 Alpha` 拆成两个实体。建议引入别名表/归一化键，写入时归并。
6. **事件候选召回未达建议线（中）**：92.9%，低于 95.0%；其中 1 条相关项与查询零词法重叠。建议先补同义词/实体别名索引，再用真实 BGE 判断语义召回缺口。
7. **精排代理无事件增益（低，待复测）**：事件 nDCG 变化 -0.013，统一搜索变化 +0.128。代理不是真实交叉编码器，需在真实 BGE + 精排环境复测后再判断。
